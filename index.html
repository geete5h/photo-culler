How matching works
  • Names are compared without the extension and without regard to case, so DSC01234.JPG matches dsc01234.arw.
  • If “Culled photos” has DSC01234.jpg, only DSC01234.arw is kept in “Photos to be culled”. If it has DSC01234.arw, only DSC01234.jpg (or .jpeg) is kept.
  • Every other JPG/ARW file in “Photos to be culled” is removed, including files with the same format as the culled one.
  • Sidecar files (DSC01234.xmp or DSC01234.ARW.xmp, also .dop and .pp3) are removed along with their photo when the sidecar option is on. A sidecar that belongs to a kept photo, or to no photo at all, is left alone.
  • Only files directly inside each folder are considered, not files in subfolders. Other file types and hidden system files (.DS_Store, ._*) are left alone.
  • Move to _rejected folder puts removed files in Photos to be culled/_rejected/. Nothing is deleted, and Undo puts them back. If a file with the same name is already there, the new one is saved as name (1).ext.
  • Delete permanently skips that step. Browsers can't use the Trash or Recycle Bin, so those files are gone for good.
  • The folders are read again whenever you come back to this tab, so the preview stays up to date.
